## 9. Limitations and delivery classification

1. **Google review listing identity — VERIFIED in a signed-in real browser** (dialog
   headed "Shree Jewellers", Place ID `ChIJwVPgCwAdwTsR7AHj3vrZvA4`). The *headless*
   re-check of the same URL is **BLOCKED** by Google's "unusual traffic"
   anti-automation interstitial from this network — a third-party bot check, recorded
   as external BLOCKED (never counted as a pass or a failure). A wrong place shown
   would still be FAILED.
2. **Production flow submission intentionally not exercised.** A valid entry on
   production would create a real customer record in the owner's live list; the
   complete flow (persist-first entry → review assistant → return screen → spin →
   bundle reveal incl. coupon → claim code → thank-you → admin Mark Collected) was
   verified on staging against the identical bundle, and production was verified
   read-only up to and including the eligibility gate. Label: flow = VERIFIED on
   staging, live surface = VERIFIED on production.
3. The review-assistant Google pop-up behaviour (popup-blocked detection) was verified
   in the automated browser against the configured destination; actual review posting
   remains entirely customer-controlled and is out of scope by design.
